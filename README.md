A program that writes one original roast line about an everyday gadget to
`/output/entry.txt` — an entry for the
[One-Line Roast: The Gadget You Use Every Day](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)
bounty on make.fun. An AI judge compares the lines pairwise on funniness,
freshness, and tight wording.

## The line

> My smartwatch buzzes to remind me to breathe, as if the last thirty years of doing it unsupervised were a fluke.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no install and no build step.
`main.py` writes `entry.txt` (112 characters, within the 1–200 gate) and
nothing else.

## Layout

- `main.py` — the entry program: writes the one-liner to `entry.txt`.
